# Study Planner

Лабораторна робота №8 з React. Це простий планувальник навчальних завдань.

## Можливості

- додати завдання через форму;
- позначити завдання виконаним або повернути в активні;
- видалити завдання;
- фільтрувати: усі, активні, виконані;
- бачити статистику завдань.

Дані зберігаються лише в пам'яті сторінки — після оновлення браузера повертаються початкові завдання. Це зроблено навмисно, бо в цій лабораторній `localStorage` ще не використовується.

## Запуск

```bash
npm install
npm run dev
```

Потім відкрий адресу, яку покаже Vite (зазвичай `http://localhost:5173`).

## Перевірка

```bash
npm run lint
npm run build
```

## Структура

- `src/components` — окремі React-компоненти інтерфейсу;
- `src/data` — стартові завдання;
- `src/types` — TypeScript-типи;
- `src/styles` — SCSS-стилі у BEM-нотації.
