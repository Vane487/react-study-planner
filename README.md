# Study Planner

Навчальний React-застосунок для планування завдань. Лабораторні роботи №8–9.

## Можливості

- додавання, редагування та видалення завдань;
- зміна стану: виконано / активне;
- фільтри: усі, активні, виконані;
- автоматична статистика;
- збереження завдань та активного фільтра у `localStorage`;
- Toast-повідомлення після додавання, редагування й видалення;
- Undoable Delete: після натискання «Видалити» є 5 секунд, щоб скасувати дію;
- кнопка «Скинути дані» для повернення стартового списку.

## Запуск

```bash
npm install
npm run dev
```

Потім відкрий адресу, яку покаже Vite, зазвичай `http://localhost:5173`.

## Перевірка

```bash
npm run lint
npm run build
```

## Структура

- `src/components` — компоненти інтерфейсу та їхні SCSS-стилі;
- `src/context` — `TaskProvider` і спільний Context;
- `src/hooks` — `useTaskContext` та `useLocalStorage`;
- `src/reducers` — чистий `taskReducer` з усіма діями над завданнями;
- `src/data` — стартові завдання;
- `src/types` — TypeScript-типи;
- `src/styles` — лише глобальні базові стилі й спільний блок кнопок.
